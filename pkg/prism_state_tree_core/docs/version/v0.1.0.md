# prism_state_tree_core v0.1.0

## ST0 语义内核

这是 StateTree 的首个可用核心切片：`TreeDef` 经结构校验编译为不可变 `Plan`，运行时以有界事件队列驱动确定性微步。

已交付：

- Atomic、Compound、Parallel 状态与稳定的活跃配置；
- Event / Eventless 迁移、priority + 声明顺序裁决、祖先迁移继承；
- LCA 生命周期、Internal / External / Self 迁移区别；
- Shallow / Deep history；
- guard、FIFO 事件队列、微步预算、生命周期与迁移日志；
- `no_std + alloc`、`forbid(unsafe_code)`，不依赖 ECS、渲染、网络或编辑器。

验证证据：`cargo test -p prism_state_tree_core --offline`（10 tests + doctest）、`cargo clippy -p prism_state_tree_core --all-targets --offline -- -D warnings`、`cargo check -p prism_state_tree_core --no-default-features --offline`。

未包含：Task/Evaluator、typed binding、instance frame、snapshot、ECS 装配、batch runtime、热重载、调试器和网络复制。这些能力属于后续 ST1–ST8，不以占位 API 宣称完成。
