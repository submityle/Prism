# prism_state_tree_core v0.1.0

## ST0 语义内核

这是 StateTree 的首个可用核心切片：`TreeDef` 经结构校验编译为不可变 `Plan`，运行时以有界事件队列驱动确定性微步。

已交付：

- Atomic、Compound、Parallel 状态与稳定的活跃配置；
- Event / Eventless 迁移、priority + 声明顺序裁决、祖先迁移继承；
- LCA 生命周期、Internal / External / Self 迁移区别；
- Shallow / Deep history；
- guard、FIFO 事件队列、微步预算、生命周期与迁移日志；
- 可校验的 no_std 快照编码/解码与原子恢复；微步预算阻断时未执行事件保留在 FIFO 队首；
- Transition 语义覆盖严格后代、祖先重入与跨 Parallel region 的配置退出，定义编译拒绝重复 child/region 及非法 history owner；
- Parallel Deep History 重入不会叠加默认 region 子状态；Parallel owner 转移后会补齐所有 region；History 请求深度必须与 owner 配置一致，否则编译期拒绝；预算错误仍保留已执行状态变化，但不返回部分 `StepReport`；
- `no_std + alloc`、`forbid(unsafe_code)`，不依赖 ECS、渲染、网络或编辑器。
- 诊断日志默认关闭；启用时由调用方设置固定容量，满后保留已有记录、置位溢出标志并让 `start`/`run` 返回 `LogCapacityExceeded`，但生命周期回调和状态变更不被截断；`clear_log` 可复位该状态。

## ST2 数据层核心契约

本版本新增了不依赖宿主存储的 binding 编译基础，作为后续 `prism_reflect` / ECS adapter 的稳定边界：

- `BindingPath` 严格解析 dotted identifier，并拒绝空段、非法字符和含糊路径；
- `BindingSlot(u32)` 表示实例帧中的稳定槽位索引；
- `EvaluatorDependency` 声明 evaluator 到输入 slot 的依赖；
- `DependencyPlan` 编译确定性反向索引，输入 slot 变化时只返回受影响的 evaluator，结果按 evaluator id 排序并去重；
- 重复 evaluator id 与同一 evaluator 的重复输入 slot 在编译期拒绝。
- 反向索引按实际使用的 slot 稀疏存储，可处理 `u32::MAX` slot；`dirty_evaluators_into` 复用调用方容量，不分配，容量不足返回 `OutputCapacity` 并清空结果。

core 不引入 `prism_reflect`、ECS `World` 或字符串热路径读取；完整的 Schema 诊断和静默实例零 tick 基准不由这一切片证明。

2026-10-14 的 ST2 增量：`FrameLayout`/`InstanceFrame` 增加对齐布局和范围检查；`SlotCodec` 编译固定宽度 typed slot 并校验稳定 GUID、版本和默认值，热路径按 little-endian 定长读写。`FrameSnapshot` 规范化 padding，以布局/Schema 指纹及校验哈希拒绝不兼容或篡改数据，失败不更改目标帧。`FrameMigration` 按 GUID 复制兼容字段、给新增字段填充默认值；同 GUID 的类型或版本变化明确拒绝。`cargo test -p prism_state_tree_core --offline` 通过 43 单测与 0 文档测试；快照创建和迁移为离线路径，单槽读写和预留缓存的依赖索引读取无分配，但整个树的热路径零分配尚未测得。

## Schema / Context 基础契约

已交付：

- 稳定的 `SchemaId`、`SchemaVersion`、`SchemaDescriptor` 与结构化 `SchemaError`。
- `SchemaCapabilities` 能力位的组合、查询与未知位拒绝。
- 只读、借用宿主上下文的 `ContextRef`，以及 `Schema::validate_context` 的 schema 身份校验。
- 该切片保持 core 的 `no_std + alloc` 边界；不引入 ECS `World`/`Entity`，不伪造 gather、typed binding 或自动调度。

2026-10-14 运行时增量：启动时预留活跃配置与进入路径容量；过渡不再克隆 `Transition`，退出、并行 region 修复与历史恢复不再建立临时状态数组；重复捕获历史复用对应 owner 的缓存；诊断日志改为显式定容并报告溢出。44 项 core 单测（包括并行深历史二次捕获缓存复用、日志容量与回调独立性回归）通过，严格 Clippy 通过。首次历史捕获仍可能分配；未测得整个运行时零分配。早期单线程 36 项验证已由本次验证取代。

此 core crate 不包含 Task/Evaluator 执行 trait、ECS gather/装配、batch runtime、热重载、调试器和网络复制；`prism_reflect` 路径解析与 typed scalar adapter 位于 `prism_state_tree_ecs` 的 `reflect` feature。其余能力不以占位 API 宣称完成。
