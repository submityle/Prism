# prism_asset v0.1.0

## 范围

- 影响 crate：`prism_asset`、`prism_asset_macros`
- 里程碑：M0–M2 运行时内核切片
- 对应设计：`prism_asset_design_zh.md` 实施状态与 §6–§12

### Added

- `Asset` 与 `VisitAssetDependencies` 派生宏及嵌套依赖遍历。
- SoftHandle 目录解析、批次预算、重复请求合并和 I/O/CPU 优先级。
- 类型化 Placeholder/Failure fallback。
- `Immediate`、`KeepAlive`、`Lru`、`Pinned` 驻留策略与硬字节/条目预算。
- 同帧 fixpoint 回收不重复推进 KeepAlive 计龄。

### Changed

- `Assets<A>` 增加 fallback、retention 和回收诊断接口。

### Deprecated

无。

### Removed

无。

### Fixed

- 防止同一次 AssetServer 回收 fixpoint 过早消耗驻留缓存寿命。

### 破坏性变更

开发期 API 尚未发布；无需保留旧 API 兼容层。完整 Cargo 测试需在工作区磁盘空间恢复后执行。
