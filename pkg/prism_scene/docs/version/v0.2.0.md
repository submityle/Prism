# prism_scene v0.2.0

## M0 + typed instantiation vertical slice

本版本把 Scene 的核心身份、模板、override、remap、常驻档位模型与首个真实 ECS 实例化切片交付到 `pkg/prism_scene`。

已交付：

- `InstantiationPlan` 校验（Local 0 是唯一层级根、无断开实体/多父/环）、`LocalEntityId` 到运行时 `Entity` 的确定性 remap；
- 全量预留实体后执行 typed Bundle/constructor，使构造器可以引用尚未 materialize 的本地实体；
- `ChildOf` 层级重连、重复父节点/环检测；
- 构造器返回错误时回收本次实例预留并 materialize 的实体；构造器通过受限 `SpawnContext` 只能 materialize 当前 constructor 所属实体、连接实例自有实体，并拒绝动态 `ChildOf` 环；因此不会借回滚误删外部实体；闭包 panic 和其他外部副作用不承诺事务回滚；
- 精确实例 despawn，包含实例映射中的 reserved structural-override entities，且外部挂接子实体不会被级联删除；
- `SceneSpawn::scene_instance` 生成实例根锚点。
- M1 通用列物化：`materialize` 模块提供按 `ComponentTypeId` 注册的安全行解码器；列行大小、对齐、payload 长度、FieldSlot bounds/重复项/目标 local、World 反射注册和类型一致性均在写入前校验；实体引用通过 `RemappedEntityField` 接收本实例的完整 `Entity`。
- 物化事务契约：结构预检不写 World；预留后先完成全部行解码和 reflected type 检查；解码失败或 ECS 插入失败会回收本次实例实体，不留下半生成实例。调用前若 World 存在其他未刷新的 reservation 则拒绝。

验证证据：当前修复后 `cargo test -p prism_scene --offline -- --test-threads=1`（68 unit tests + 1 doctest）；覆盖多行列物化、FieldSlot remap、缺注册、decoder 失败回滚。`prism_scene` 自有代码 clippy `--no-deps -D warnings` 曾通过，完整 workspace clippy 受依赖 `prism_asset/src/scheduler.rs` 的既有 lint 阻塞。

诚实边界：列格式仍要求每个已注册组件提供应用侧安全 decoder；本模块不把字节 reinterpret 为 Rust 值，也不自动推断任意 Rust 类型的实体字段。SIMD remap、bake 二进制包、streaming、hot reload、proxy/residency 运行时和持久化仍未实现。no_std 无法可移植地捕获 decoder 闭包 panic；panic 及其外部副作用不享有事务保证。
