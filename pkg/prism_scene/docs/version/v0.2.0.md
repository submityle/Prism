# prism_scene v0.2.0

## M0 + M1 + M2 validation vertical slices

本版本把 Scene 的核心身份、模板、override、remap、常驻档位模型与首个真实 ECS 实例化切片交付到 `pkg/prism_scene`。

已交付：

- `InstantiationPlan` 校验（Local 0 是唯一层级根、无断开实体/多父/环）、`LocalEntityId` 到运行时 `Entity` 的确定性 remap；
- `LocalEntityId::checked_reserved` 与溢出拒绝：保留段 offset 不会在 release 构建回绕到 base 段；旧的 `reserved` 构造器对不可表示输入明确 panic。
- 全量预留实体后执行 typed Bundle/constructor，使构造器可以引用尚未 materialize 的本地实体；
- `ChildOf` 层级重连、重复父节点/环检测；
- 构造器返回错误时回收本次实例预留并 materialize 的实体；构造器通过受限 `SpawnContext` 只能 materialize 当前 constructor 所属实体、连接实例自有实体，并拒绝动态 `ChildOf` 环；因此不会借回滚误删外部实体；闭包 panic 和其他外部副作用不承诺事务回滚；
- 精确实例 despawn，包含实例映射中的 reserved structural-override entities，且外部挂接子实体不会被级联删除；
- `SceneSpawn::scene_instance` 生成实例根锚点。
- M1 通用列物化：`materialize` 模块提供按 `ComponentTypeId` 注册的安全行解码器；列行大小、对齐、payload 长度、FieldSlot bounds/重复项/目标 local、World 反射注册和类型一致性均在写入前校验；实体引用通过 `RemappedEntityField` 接收本实例的完整 `Entity`。
- 物化事务契约：结构预检不写 World；预留后先完成全部行解码和 reflected type 检查；解码失败或 ECS 插入失败会回收本次实例实体，不留下半生成实例。调用前若 World 存在其他未刷新的 reservation 则拒绝。
- M2 override validation slice：`OverrideSet::validate_for_template(entity_count)` 与模板感知的 `validate_for_template_with_hierarchy` 返回结构化 `OverrideError`；校验属性目标为 base 或已声明的 AddEntity local、reserved local 连续分配、父实体、删除时不留下活子实体，以及组件操作目标/重复。`compose_layers` 对跨层重复结构操作返回带 layer index 的结构化错误，并清理实体/组件删除造成的属性孤儿。
- `SceneTemplate::validate_overrides` 将完整模板 hierarchy 接入 override 校验，避免仅传 entity count 时遗漏父子悬空检查。
- `encode_plan` / `decode_plan` 提供 version-1 的确定性 `InstantiationPlan` 二进制契约；解码具备 checked 长度/集合/列字节预算、魔数/版本/尾部校验，并在构建后重新执行完整 plan validation。列数据保持 opaque bytes，不在 codec 中 reinterpret 为 Rust 值。

验证证据：`cargo test -p prism_scene --offline -- --test-threads=1` → **90 unit + 1 doctest 全绿**；`cargo check -p prism_scene --offline --no-default-features` 通过；目标 crate `cargo clippy -p prism_scene --offline --all-targets --no-deps -- -D warnings` 通过。全依赖严格 clippy 被未修改的 `pkg/prism_asset/src/server.rs` `clippy::let_and_return` 阻断；override 校验覆盖连续 reserved local、层级悬空、组件孤儿和跨层结构冲突。既有 M1 测试覆盖多行列物化、FieldSlot remap、缺注册、decoder 失败回滚。

诚实边界：override validation 是结构校验，不持有 base archetype 的组件清单，因而不能证明 RemoveComponent 对应组件在基体中存在；属性路径/值只校验目标结构，不做反射路径解析、类型匹配或序列化合法性检查。列格式仍要求每个已注册组件提供应用侧安全 decoder；本模块不把字节 reinterpret 为 Rust 值，也不自动推断任意 Rust 类型的实体字段。SIMD remap、streaming、hot reload、proxy/residency 运行时和持久化仍未实现。当前 plan codec 是 bake/runtime 的数据契约，不等于完整 `prism_scene_bake` 资产管线。no_std 无法可移植地捕获 decoder 闭包 panic；panic 及其外部副作用不享有事务保证。
