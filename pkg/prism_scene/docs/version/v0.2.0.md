# prism_scene v0.2.0

## M0 + typed instantiation vertical slice

本版本把 Scene 的核心身份、模板、override、remap、常驻档位模型与首个真实 ECS 实例化切片交付到 `pkg/prism_scene`。

已交付：

- `InstantiationPlan` 校验、`LocalEntityId` 到运行时 `Entity` 的确定性 remap；
- 全量预留实体后执行 typed Bundle/constructor，使构造器可以引用尚未 materialize 的本地实体；
- `ChildOf` 层级重连、重复父节点/环检测；
- 构造失败的完整回滚；
- 精确实例 despawn，且外部挂接子实体不会被级联删除；
- `SceneSpawn::scene_instance` 生成实例根锚点。

验证证据：`cargo test -p prism_scene --offline`（58 unit tests + 1 doctest）、`cargo fmt --manifest-path pkg/prism_scene/Cargo.toml -- --check`、`cargo check -p prism_scene --offline`，以及针对本 crate 的 `cargo clippy --all-targets --no-deps -- -D warnings`。

诚实边界：opaque column payload 的通用 materialization、SIMD remap、bake 二进制包、streaming、hot reload、proxy/residency 运行时和持久化仍未实现；它们继续由设计文档的后续里程碑负责，不由本版本的 typed slice 冒充完成。
