# prism_scene v0.4.0

## Crate-local runtime contract

本版本完成 `prism_scene` 内核的可执行契约：

- `spawn_scene` 与 `spawn_scene_with_registry` 提供事务化 typed 实例化；失败会清理本次实例拥有的实体。
- `OverrideSet` 支持确定性的属性覆盖与结构操作；registry replay 对 Add/RemoveEntity、Add/RemoveComponent 和属性写入执行预检、提交及回滚。
- `spawn_nested_typed` 提供有界递归、GUID 环检测、子树所有权和反向 teardown。
- `ScenePlanCost`、`ResidencyScheduler` 提供不解码成本统计及按 `PersistentId` 稳定排序的实体/字节预算调度。
- PRST/PMNF v1 plan、template、manifest codec 提供严格 wire 校验、资源预算和确定性 round-trip。
- `SceneInstancePersistence` 与 `SceneReloadPlan` 提供 persistent-id-first 的 delta capture、模板 diff、结构状态重建和孤儿诊断。

## Explicit boundaries

`prism_scene` 不拥有文件 I/O、source import、CAS/mmap、schema migration、空间索引、proxy⇄ECS 执行器或 GPU 资源上传；这些系统消费本版本固定的数据契约。结构 payload 必须由应用注册 typed decoder，opaque bytes 不会被猜测或 reinterpret 为 Rust 值。
