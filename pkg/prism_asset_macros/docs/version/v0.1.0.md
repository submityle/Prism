# prism_asset_macros v0.1.0

## 范围

- 影响 crate：`prism_asset_macros`、`prism_asset`。
- 里程碑：M0，资产身份与依赖声明基础切片。
- 对应设计：[prism_asset_macros_design_zh.md](../prism_asset_macros_design_zh.md) §1–4。
- 验证状态：代码与测试已落地，Cargo 验证由主代理统一执行，不代表发布完成。

### Added

- `Asset` 派生：稳定身份与强/软引用自动遍历。
- `VisitAssetDependencies` 派生及容器组合、显式 dependency / skip 属性。
- `AssetDependency`、完整引用 visitor 和 collection 便利函数。
- 泛型资产、union 与无效属性的编译期诊断；重命名 crate/facade 路径支持。
- 独立 AST、no_std consumer、运行时遍历及 compile-fail doctest。

### Changed

- 运行时 lib/prelude 同时导出 derive 宏与 trait。

### Deprecated

无。

### Removed

无。

### Fixed

- 支持的直接/嵌套句柄由宏生成依赖列表，减少手写漏登风险。
- 软 GUID 不转换为运行时 slot，也不隐式加载或保活。

### 破坏性变更

无破坏性变更。已有手写 Asset 可逐个替换为 derive；稳定 `TYPE_NAME`
须用 `#[asset(type_name = "原名称")]` 保留，避免身份重命名。
别名/自定义分组须显式 `#[dependency]`；不要同时 derive 两个宏以免重复实现 visitor。
