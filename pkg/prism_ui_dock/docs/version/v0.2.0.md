# prism_ui_dock v0.2.0

## Persistence core

已交付：

- `encode_layout` / `decode_layout` 的稳定 little-endian 二进制格式，包含 magic 与版本号。
- 输入长度、集合数量、节点数量、树深度、字符串长度和枚举值的边界检查。
- 解码后的布局不变量校验；不接受坏比例、重复归属、空浮窗等非法状态。
- 最大化恢复态要求当前可见面严格收敛为快照中的唯一面板；非法状态在持久化编码和 renderer 消费前均被拒绝。
- 可选的已知 panel/document 注册表过滤；未知内容会安全折叠空分支，并重算 active 索引与剩余 split 比例。
- 主布局、浮窗、auto-hide 和 maximize restore 的确定性往返测试。

## Panel registry 基础契约

已交付：

- `PanelDescriptor` 的稳定 ID、显示/可访问性元数据、实例策略、默认槽位和初始可见性。
- `PanelRegistry` 的确定性注册顺序、空白/重复 ID 拒绝、查询和迭代。
- `decode_layout_with_registry` 将 Registry 作为持久化 panel allow-list，保留旧的切片式 `decode_layout` API，并避免调用方复制 ID 列表。
- 纯 `no_std + alloc` 数据边界；不把 Element、GPU 句柄或 panel factory 假装成 core 能力。

## Registry 默认布局物化

已交付：

- `PanelRegistry::default_layout(DefaultLayoutPolicy)` 按确定性注册顺序收集可见面板，将同一默认槽位合并为稳定 tab stack，并把 Document 槽位映射为中央工具 tab stack；不伪造 `DockNode::Document`。
- Left/Right/Bottom 的固定点权重使用最大余数稳定分配；空槽位不产生空的非根节点，Floating 面板生成非零矩形和唯一递增 z 序。
- 生成结果立即经过完整 `DockLayout::validate`；非法比例、空浮窗和溢出均返回结构化错误。`Instancing::Multi` 只表示未来可多实例，本切片每个 descriptor 仍只生成一个默认实例。
- 回归覆盖注册顺序、隐藏面板、空 registry、槽位组合、Floating z 序和 layout codec round-trip。

## Workspace / Perspective 纯数据管理

已交付：

- `WorkspaceManager`、`Workspace` 与 `Perspective` 的命名纯数据契约。
- Workspace 与 Perspective 均按插入顺序保存；空白名称和重复名称以结构化错误拒绝，失败操作不改变状态。
- 保存和切换布局均使用 `DockLayout` 深拷贝边界，不共享可变布局状态。
- 仅提供内存管理和选择，不包含文件 IO、自动保存、renderer、Element 或 panel factory。

## Workspace 持久化 codec

已交付：

- `encode_workspace` / `decode_workspace` 提供带 magic/version 的稳定 Workspace/Perspective 二进制快照。
- 每个 Perspective 的 `DockLayout` 复用既有布局 codec，执行嵌套资源上限、active 引用校验、UTF-8/枚举/截断/尾随字节校验。
- `decode_workspace_with_registry` 将 `PanelRegistry` 作为嵌套布局的 panel allow-list；未知 panel 由布局 codec 安全过滤。
- 该 codec 只处理内存字节，不执行文件 IO、自动保存或 renderer 装配。

## `std` 文件存储边界

已交付：

- `WorkspaceFileStore` 通过 sibling lock、唯一临时文件、`sync_all` + rename 提交快照；在 Unix 上同步父目录，并在失败路径清理临时文件。
- 覆盖 primary 前先验证旧快照，再以独立的同步临时文件更新 `last-good`；加载按 primary → last-good → caller default 顺序回退，并保留结构化诊断。提供 `load_with_registry` 防止未知 panel 直接进入上层。
- 文件系统适配仅在 `std` feature 下导出，不污染 `no_std + alloc` 核心模型与 codec。

尚未交付：schema 迁移链、自动保存 middleware、上层 factory、真实 Element/renderer 装配和 overlay 预览。默认布局物化仍是纯数据边界，不创建 Element、GPU 句柄或 panel factory。
