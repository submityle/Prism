# prism_ui_dock v0.2.0

本版本提供可验证的停靠布局、渲染、持久化、迁移、输入、可达性、动画、实例和运行时指标能力。核心模型保持 `no_std + alloc`，文件系统、Element 和 GPU 适配均通过 feature 接入。

## 布局与交互

- `DockLayout`、`DockNode`、Document、floating、auto-hide 和 maximize restore 具有确定性模型与完整不变量校验。
- reducer 以候选状态、normalize、validate、提交的事务顺序执行；失败 action 不修改原状态。
- drag/drop 覆盖 center、四向 split、tab insertion、floating z 命中、取消和窗口失焦恢复。
- `DockHost` 统一持有布局、历史、revision、RenderPlan cache 和运行时指标；输入树由 `prism_ui_input` host 持有，dock 通过 preview hit-node helper 提供透明覆盖层几何。

## RenderPlan 与 Element

- `solve_with` 输出 main、floating、auto-hide、maximize、panel、document、tab、splitter 和 focus 几何。
- `DockView::render_plan` 消费已求解计划；它校验计划中的 panel、document、floating 身份与当前布局一致，再调用 active factory。
- inactive tab 只生成标题元数据；active panel、document、floating 和 auto-hide reveal 生成内容 Element。
- `DockHost::render_element` 生成 `DockHost -> RenderPlan -> DockView -> Element`；外部 renderer host 再调用 `ElementRenderer` 生成 `DrawList`，并选择 CPU 或 wgpu rasterizer。
- factory 支持结构化错误、注销、只读 `ViewFactoryContext` 和 generation 检查；失败不会提交部分 Element 树。

## 持久化与迁移

- `PRDK` 与 `PRWS` 使用 little-endian、版本号、checked length/count、UTF-8、枚举和严格尾随数据校验。
- `MigrationRegistry::with_legacy_v0` 与 `WorkspaceMigrationRegistry::with_legacy_v0` 提供 v0 到 v1 的真实转换。
- 迁移在 canonical decode 前执行 caller byte limits；转换结果再次经过完整 codec 校验。
- 测试覆盖合法 v0、缺失迁移边、截断、非法 UTF-8、尾随数据和调用方资源限制。
- `WorkspaceFileStore` 使用 sibling lock、同步临时文件、平台原子替换、last-good 恢复和父目录同步；workspace 与独立 `PRIN` 实例文件都支持 primary/last-good 恢复，macOS 验证覆盖重复保存、并发写入、损坏恢复和原子替换。
- `WorkspaceAutosave` 提供 host-driven debounce、flush、失败保持 dirty 和成功清理 dirty。

## Registry 与实例

- `PanelRegistry` 保存稳定 descriptor、可访问性元数据、默认槽位和实例策略。
- `Instancing::Singleton` 与 `Instancing::Multi` 均通过 host-owned instance registry 执行稳定 instance identity、创建、关闭、恢复和重复约束。
- 默认布局为每个可见 descriptor 物化稳定 panel ID 和确定性几何；运行时实例由 `PanelInstanceRegistry` 显式创建、关闭、恢复。`PRIN` codec 保存稳定实例 ID、panel ID、open/closed 状态和 next ID，`WorkspaceFileStore::save_instances/load_instances` 负责保存和恢复注册表。

## 视觉、动画与输入

- drop preview 根据 center、split 和 tab insertion 输出不同语义 class、主题 token、背景、边框和对比度约束。
- preview 使用 absolute geometry，并通过 `PointerEvents::None` 排除 hit-test；它不会修改布局或抢焦点。
- motion 覆盖 disabled、reduced-motion、normal、high-quality，支持 main、floating、auto-hide reveal、maximize、restore 和 retarget。
- 动画插值 RenderPlan 的主区、浮窗、auto-hide bar/reveal 和 maximize/restore 几何；新 action 以当前采样几何为起点，不累积旧时间线。

## 性能与维护

- RenderPlan cache 的 key 包含 layout fingerprint、viewport 和 `LayoutMetrics`；任一输入变化都会重新求解。
- tab window 保留 active、keyboard neighbor、drag source 和 drop target，并使用 overscan 限制 Element 数量。
- metrics collector 固定容量 256；host 通过有序 `DockFrameSample` 注入各阶段样本，collector 输出阶段耗时与 DrawList/visible/factory 三类计数的 P50/P95/P99。
- `DockHost` 提供 frame instrumentation；renderer host 在完成 Element、DrawList、GPU 和 present 后提交一个不可变样本，summary 同时输出阶段时延和 DrawList/visible/factory 计数的 P50/P95/P99。
- 纯数据、solver、Element、GPU、文件和可达性各自拥有唯一状态来源，适配器只进行类型转换。
