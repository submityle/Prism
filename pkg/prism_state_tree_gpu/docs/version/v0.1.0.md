# prism_state_tree_gpu v0.1.0

首个版本实现固定宽度 StateTree GPU batch evaluator。输入 ABI 为 10 个 `u32`（40 字节），输出 ABI 为 12 个 `u32`（48 字节）；PlanRevision 通过 uniform 传递，Q16 乘法、符号扩展、饱和状态和结果校验均有 CPU golden 对照。

2026-10-15 在 Apple M2 / Metal 上完成真实设备验证：8 行 parity 和 4,096 行规模测试通过，规模测试 P50 `3,007,041 ns`、P95 `4,550,500 ns`、P99 `5,176,833 ns`。沙盒无设备时同一测试保留 graceful skip；该 skip 不被记录为 GPU 执行证据。
