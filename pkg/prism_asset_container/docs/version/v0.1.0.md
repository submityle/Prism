# prism_asset_container v0.1.0

## 范围

- 影响 crate：prism_asset_container
- 里程碑：M5（本地容器切片，不代表完整 M5 完成）
- 对应设计：`prism_asset_container_design_zh.md` §1–§4；
  总设计 `prism_asset_design_zh.md` §10.5、§23.7。

### Added

- `ContainerReadLimits`、共享 `ContainerReadBudget`、预算计数和显式构造入口。
- `ContainerReader`/`ManifestReader::read_range_owned`，在输出分配前执行限额。
- 10 项不可信输入、并发预留、批次去重与 VFS 接线回归测试。

### Changed

- v2 压缩挂载最多同时保留一个解码 Chunk。
- 压缩批次按 payload/Chunk 去重解码，保留调用方输出顺序。
- 默认读取现执行资源上限；超限返回结构化 `ResourceLimit`。

### Fixed

- 压缩批次后续请求非法时，不再先读取前面的有效请求。
- Manifest/VFS 不再在容器预算检查前分配 owned-range 输出。

### 破坏性变更

开发期默认资源限额可能拒绝此前可读取的大文件/单元；调用方须根据实际
驻留与并发预算显式设置 `ContainerReadLimits`，而不是依赖无限分配。
`ContainerError` 新增资源拒绝与分配失败变体；穷尽匹配须同步更新。
