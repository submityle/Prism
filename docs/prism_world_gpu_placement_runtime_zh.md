# World streaming placement runtime slice

本切片把 world streaming 的剩余可落地部分限制在两个 engine-neutral 契约内：

- `prism_world_runtime::WorldCellStore` 维护 resident cell 与 `PersistentId` 的稳定索引。索引支持多 cell、跨 cell `relocate`、cell replacement/eviction，以及有明确 byte/cell/object 上限的 canonical restart snapshot。
- `StableRefSceneHost` 是 `SceneHost` 的生命周期适配器。stable-ref decoder 必须由产品 scene 提供，不假设 cell payload 格式；decode/store validation 失败不会调用 scene host，scene host load/reload 失败保留旧索引，eviction 只有在 host 成功后才删除索引。
- `prism_world_gpu::PlacementRenderGraph` 生成确定性的多 cell `Upload → Project → Compact → DrawIndirect` pass plan，并显式声明 source、placement、compact、indirect、scene 的资源读写关系。相同 cell/revision 或同一 cell 的冲突 revision 会在发布 graph 前拒绝；`PlacementGraphEncoder` 将已验证的 plan 逐 pass 交给 renderer-owned consumer，失败返回精确的 pass index、cell/revision 与 stage，且不分配、不重排、不合并 pass。
- `prism_world_gpu::build_placement_render_graph` 将 renderer 已注册的真实 RHI buffer、scene texture、pipeline 与 bind group identity 降低为 `prism_render_graph::RenderGraph`。每个 cell 固定记录 `reset → source → project → field/compact → finalize` 五个 compute pass 和一个 indirect raster pass；所有 bind group 可见 buffer 都进入 graph 读写声明，scene attachment 通过 SSA handle 串接，多 cell 按稳定 cell/revision 顺序记录。零字节 buffer、零维 dispatch、未按四字节对齐的 indirect offset 与同 cell 重复输入在返回 graph 前 fail-closed。

验证覆盖：runtime 多 cell load、跨 cell resolve/relocation、reload 失败保持旧状态、eviction 后不可解析、磁盘 restart round-trip；GPU plan 的排序、hazard chain、重复/冲突 revision rejection，以及 encoder 对每个 pass 的顺序投递和精确失败定位。新增 Null RHI command-recording 回归核对每 cell 五次 compute dispatch、一次 indirect draw、稳定跨 cell 顺序和所有前置拒绝条件，证明 backend-neutral RenderGraph lowering 可编译并可记录命令。2026-10-20 在独立离线 target 上，`cargo test -p prism_world_gpu --features gpu --lib --offline` 为 118/118，`cargo test -p prism_world_runtime --lib --offline` 为 104/104；验证后清理 702.6 MiB target。该测试不冒充生产 renderer：真实 RHI resource registry、pipeline/bind-group registration、submission/completion retirement 仍由 renderer 负责；raw `GpuHeightfieldPlacement` 到这些 imported RHI identity 的产品接线、`prism_render_scene` mesh/material/unified visibility 消费和产品 scene/ECS decoder 尚未交付。
