# 内容缩略图生产与缓存

更新日期：2026-10-20。`prism_editor_content::thumbnail` 读取实际 PNG 文件，输出不可变 `Arc<Thumbnail>`，由宿主上传 GPU。该模块不依赖 Bevy，不把文字资产卡片计作缩略图显示。

## 调用与所有权

每个项目共享一个 `ThumbnailService`，克隆共享并发和缓存额度。`request(ThumbnailKey)` 在调用线程只校验参数、查缓存和启动 worker；文件读取、PNG 解码和缩放均在工作线程进行。宿主通过 `is_finished`/`poll` 非阻塞消费结果，并自行安排事件循环唤醒。Key 包含稳定 `AssetId`、宿主提供的 `u128` 源修订、绝对路径及输出包围框。源内容变化必须改变修订；服务不以 mtime 代替内容修订。缓存命中不会重新访问源文件。

运行中和已完成但未消费的请求都占用并发额度，包括缓存命中。丢弃请求只发出取消，不 join；工作线程仍持有额度，直到阻塞调用和清理结束。`cancel` 也撤销已经完成但未消费的结果。只有成功消费才插入缓存。`clear` 清空缓存并撤销此前请求的私有 epoch，旧 worker 和缓存命中不能重新填入已关闭项目。不同 worker 的旧修订仍可作为不同 Key 保留，宿主展示时必须检查当前资产修订。

## 图像处理

支持静态 PNG 的 RGB/RGBA/灰度/灰度透明及调色板输入，展开低位深和透明表；16 位输入先取高 8 位。按原始比例缩入请求包围框，整数四舍五入，绝不放大。面积滤波在线性光、预乘透明度空间累积，再转换为直通透明度 sRGB RGBA8，避免透明蓝色污染不透明红色、黑白缩小变暗等错误。没有额外的完整 RGBA 源图副本。

带 sRGB 标记或无色彩标记的输入使用 sRGB；仅有 gAMA 的输入按声明的幂函数解码，并假定 sRGB 原色。APNG、ICC、cICP/HDR 元数据及未标 sRGB 的显式原色声明返回 `UnsupportedFormat`，不能静默按 sRGB 显示。完整色彩管理的转换器接入仍须独立实现；此处不宣称支持所有资产格式或 HDR 色调映射。PNG 解码及 `finish` 检查格式、CRC 和结尾，失败不发布图片。

## 预算、性能和边界

默认最多 4 个未消费请求；单源编码 32 MiB、源像素 16 Mi、PNG 内部预算 128 MiB；输出边长 512、包围框 RGBA 1 MiB；缓存 512 项/64 MiB 像素；路径 4096 字节；协作截止时间 10 秒。零缓存预算禁用缓存。缓存按最近使用淘汰，时间戳溢出时保留原顺序；清理/淘汰不使调用者持有的像素失效。像素缓存字节不计调用者 Arc、Key/索引和 allocator 开销；编码 Vec 的扩容与解码帧亦独立于 PNG 内部预算。

缩放成本与源像素和输出像素有关，每个源像素最多参与四个缩小覆盖区。读取每 16 KiB 检查取消，缩放按输出行、源行及最多 4096 个水平采样间隔检查。PNG 单次解码调用和 OS 文件调用不能被标准库强制中断，截止时间是协作式，不能当作硬实时隔离。

叶子符号链接、目录和特殊文件拒绝；读取前/打开后/解码后核对普通文件、长度和修改时间，Unix 另核对设备/inode。检查用于发现普通并发写入，不是敌对文件系统的事务快照；祖先路径不提供沙盒隔离，保持元数据不变的修改须由宿主源修订或外部存储协议检测。

## 实际验证

14 项真实临时 PNG 文件回归覆盖格式归一化、低/高位深、透明调色板、线性光和透明边缘、gamma 转换、不放大/比例、APNG/显式原色拒绝、CRC/截断（含缺 IEND）、各分配预算、并发额度、缓存命中/LRU/修订/路径/尺寸身份、取消/clear 围栏、drop 后清理及超时。定向严格 Clippy 通过。

```sh
cargo test --offline -p prism_editor_content --test thumbnail
cargo clippy --offline -p prism_editor_content --lib --test thumbnail --no-deps -- -D warnings
```
